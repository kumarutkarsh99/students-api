# Students API

A RESTful CRUD API for student records, built with Go's standard HTTP server and SQLite.

## Requirements

- Go 1.27.1 or later

## Run locally

```sh
git clone https://github.com/kumarutkarsh99/students-api.git
cd students-api
cp configs/local.example.yaml configs/local.yaml
go mod download
go run ./cmd/students-api -config=configs/local.yaml
```

The server listens on `localhost:8082` by default. SQLite creates the configured database and its parent directory when the service starts. The local configuration and database are ignored by Git.

You can also set `CONFIG_PATH` to the configuration file path instead of passing `-config`.

## API

All request and response bodies use JSON. Student fields are:

```json
{
  "id": 1,
  "name": "Ada Lovelace",
  "email": "ada@example.com",
  "age": 36
}
```

`id` is generated by the API. `name` and `email` are required (maximum lengths 100 and 254 characters), email must be valid, and age must be a positive integer. Leading and trailing whitespace is trimmed from names and emails. Unknown request fields are rejected, and request bodies are limited to 1 MiB.

| Method | Endpoint | Description | Success |
| --- | --- | --- | --- |
| `POST` | `/api/students` | Create a student | `201 Created` with student and `Location` header |
| `GET` | `/api/students` | List students, ordered by ID | `200 OK` with an array (empty array when none exist) |
| `GET` | `/api/students/{id}` | Get a student | `200 OK` with student |
| `PUT` | `/api/students/{id}` | Replace a student's editable fields | `200 OK` with updated student |
| `DELETE` | `/api/students/{id}` | Delete a student | `204 No Content` |

### Create

```sh
curl -i -X POST http://localhost:8082/api/students \
  -H "Content-Type: application/json" \
  -d '{"name":"Ada Lovelace","email":"ada@example.com","age":36}'
```

### Read

```sh
curl http://localhost:8082/api/students
curl http://localhost:8082/api/students/1
```

### Update

`PUT` replaces all editable fields, so send the complete representation:

```sh
curl -i -X PUT http://localhost:8082/api/students/1 \
  -H "Content-Type: application/json" \
  -d '{"name":"Ada Byron","email":"ada@example.com","age":37}'
```

### Delete

```sh
curl -i -X DELETE http://localhost:8082/api/students/1
```

Errors use a JSON object with an `error` message. Invalid IDs or request bodies return `400`, a valid ID with no matching student returns `404`, and unexpected server/storage failures return `500` without exposing internal error details.
